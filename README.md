# GradeApp Mobile

Flutter-приложение GradeApp для ученика, родителя и учителя. Работает на тех же API, что и веб (`gradeapp/backend`). Дизайн — система «Веер» (`docs/design/`), продукт — `docs/product/`.

## Запуск

```bash
flutter pub get
flutter run --dart-define=API_BASE_URL=http://localhost:8001/api   # локальный бэкенд
flutter run                                                         # прод: https://grade-app.kz/api
```

Базовый URL обязательно с `/api`. Android-эмулятор ходит на хост через `http://10.0.2.2:<port>/api`. После смены нативных зависимостей (камера, шрифты) нужен полный `flutter run`, hot restart не подхватит.

Проверки (их же стоит гонять в CI):

```bash
flutter analyze   # ноль замечаний
flutter test
```

## Пуши (FCM)

Без конфигурации Firebase пуши выключены, остальное работает. Чтобы включить:

1. Создать проект Firebase, добавить приложения iOS и Android с bundle id `kz.gradeapp.gradeapp`.
2. Загрузить в Firebase APNs-ключ (.p8) из Apple Developer (Project settings → Cloud Messaging).
3. Скопировать `firebase.example.json` в `firebase.json` (он в `.gitignore`), заполнить значениями из настроек приложений в Firebase.
4. Запускать с `--dart-define-from-file=firebase.json`.
5. На бэкенде: сервисный аккаунт Firebase (JSON) в переменную `FCM_SERVICE_ACCOUNT`. Отправка — `backend/users/fcm.py`.

Как устроено:
- токен уходит на `POST /api/push/devices/` после входа и только если уведомления разрешены; при выходе — `DELETE`;
- разрешение спрашивается один раз, с пояснением: у ученика после первой отметки «Я в школе», у родителя и учителя через пару секунд после первого открытия;
- в открытом приложении пуш — тост с кнопкой «Открыть»; тап по системному пушу открывает экран по карте §4.3 спеки (и при холодном старте);
- текст пуша собирает сервер на языке пользователя, оценок и баллов в нём нет;
- Android: канал на каждую группу настроек; iOS: бейдж = непрочитанные в колокольчике;
- настройки групп — профиль → «Уведомления» (`notification_prefs`, канал `push`).

## Возможности этапа 2

- **В сети**: зелёная точка на аватарах людей (`GET /presence/`, один батч на экран, опрос раз в 30 с только на переднем плане, 404 — молча выключено). Аватар человека — `PersonAvatar` (`features/common/presence.dart`).
- **Блокировка приложения** (профиль, по умолчанию выкл.): Face ID / отпечаток / код телефона при запуске и после 5 минут в фоне (`local_auth`, `features/shell/app_lock.dart`).
- **Табель** (оценки → «Табель за …»): PDF с `/grades/period/report_card/`, системное меню «Поделиться».
- **Отзывы учителей**: ученик и родитель видят их в «Оценках»; учитель пишет из урока (долгое нажатие на ученика → «Отзыв ученику»), через офлайн-очередь.
- **Вложения к ДЗ**: показ и открытие у ученика/родителя; учитель прикладывает фото и файлы при выдаче ДЗ (файлы идут только онлайн, без сети текст уходит через очередь).
- **Крэши и аналитика**: всё на нашем сервере. Крэши — `POST /analytics/crashes/` (без входа, очистка e-mail/телефонов/токенов/query на телефоне, очередь до 20), события — `POST /analytics/events/`. Сторонних SDK нет. В debug-сборке долгое нажатие на «О приложении» в профиле вызывает тестовый сбой. Решение по приватности — `docs/product/privacy.md`.
- Карточка урока раскрывается через Hero (страничный маршрут вместо modal-sheet: Flutter не летает героями в модальные шиты).

## Платформа: действия в пушах, ссылки, виджеты, Live Activity

Код — `lib/features/platform/`, нативная часть — `ios/GradeAppWidgets`, `ios/Runner/LiveActivity.swift`, `android/.../widgets`. Контракт с бэкендом — `docs/product/contracts-stage2.md`.

**Кнопки в пушах.** `attendance.flagged` → «Объяснить пропуск» (форма отпроса для этого пропуска: урок по `/attendance/<id>/`, иначе день), `excuse.pending` → «Одобрить» (`POST /excuses/<id>/approve/`, хаптик и тост) и «Открыть».
- iOS: категории `ATTENDANCE_FLAGGED` / `EXCUSE_PENDING` регистрирует `flutter_local_notifications` (`LocalNotifications._categories`, названия на языке приложения). Нажатую кнопку отдаёт `firebase_messaging` как `RemoteMessage.actionIdentifier`; делегат `UNUserNotificationCenter` остаётся у цепочки `FlutterAppDelegate`, `flutter_local_notifications` берёт только свои локальные уведомления. Все кнопки открывают приложение (`foreground`): «Одобрить» выполняется и подтверждается тостом.
- Android: для этих двух типов сервер шлёт data-only; `firebaseBackgroundHandler` (`push_background.dart`, изолят с `Firebase.initializeApp`) рисует уведомление сам с кнопками. «Одобрить» работает без открытия приложения (фоновый изолят, свой `ApiClient`), результат заменяет уведомление. Видимость всегда `private`: на защищённом экране блокировки система показывает свою обезличенную версию (`flutter_local_notifications` не умеет `publicVersion`).
- Парсинг и выбор действия — `push_intent.dart` (чистый, покрыт тестами). `checkin.missing` ведёт на «Сегодня» родителя с выбранным ребёнком.

**Тихая синхронизация.** `sync.today` / `sync.schedule` (data-only) → `PlatformSync.refresh`: перечитывает «сегодня» и неделю в тот же кэш, что читают экраны (`cacheKeyOf`), пересобирает снимок для виджетов и напоминания учителя. В открытом приложении ещё и сбрасывает провайдеры экранов. В пуше нет `student_id`, поэтому у родителя обновляются все дети. Тот же refresh идёт при старте, возврате в приложение, смене роли и ребёнка. Выход очищает виджеты и напоминания.

**Ссылки (C7).** `https://grade-app.kz/student|parent|teacher/lesson|…` → экран по таблице в `deep_links.dart` (`routeForWebLink`), тот же набор путей в `AndroidManifest.xml` (`autoVerify`) и в `applinks:grade-app.kz` (`Runner.entitlements`). Ссылка без входа ждёт (`pendingLinkProvider`) и открывается после входа. Виджеты и уведомление урока открывают `gradeapp://app/<маршрут>` (своя схема).

**Виджеты W1, W2.** Приложение пишет один JSON-снимок (`widget_snapshot.dart`: уроки на 4 дня, ДЗ на завтра, подписи на языке приложения, время обновления) через `home_widget` (iOS: App Group `group.kz.gradeapp.gradeapp`, Android: `HomeWidgetPreferences`). Нативная часть только раскладывает: выбирает урок по часам телефона и ничего не придумывает. iOS: расширение `GradeAppWidgets` (WidgetKit, таймлайн по звонкам, обратный отсчёт `Text(style: .timer)`, lock screen: rectangular, inline, circular; Onest внутри). Android: `NextLessonWidget` 2×2 и `DayWidget` 4×2 на RemoteViews, отсчёт `Chronometer`, будильник на ближайший звонок. Данные старше суток — «Откройте приложение, чтобы обновить»; «Обновлено в …» всегда на виджете. Токены повторены в `Tokens.swift` и `res/values*/widget_colors.xml`. Расширение к проекту добавляет скрипт `ios/scripts/add_widget_extension.rb` (gem `xcodeproj`, команда `cd ios && ruby scripts/add_widget_extension.rb`; повторный запуск ничего не делает).

**Live Activity W5.** Старт, обновление и конец локальные, из экрана урока (`lesson_live.dart`): запускается, когда урок идёт и учитель начал его; «Отмечено n/m» обновляется с отметками; «Завершить урок» убирает сразу; после звонка показывает «Урок закончен» и через 15 минут снимается. Без ФИО и оценок. Кнопка «Все на месте» (W5): iOS — `Link` на `gradeapp://app/lesson/<id>?all_present=1` (на лок-скрине и в раскрытом острове), Android — действие уведомления с `showsUserInterface`; приложение открывает урок и делает ту же перекличку, что кнопка внизу экрана урока (записанные при check-in отсутствия/опоздания не трогает), хаптик + тост, счётчик в активности обновляется. Повторное открытие ничего не шлёт (`AllPresentGate` и «пишем только несохранённых»). Разбор ссылок — `lesson_link.dart`. iOS: ActivityKit (`ios/Runner/LiveActivity.swift`, вид в расширении). У iOS нет таймера «закончить само»: пока жив процесс, конец ставит таймер, иначе при следующем запуске и возврате (`LessonLive.sweep`); до этого лок-скрин сам показывает «Урок закончен» (stale-дата = звонок). Android: ongoing-уведомление с обратным отсчётом и прогрессом, `timeoutAfter` = звонок + 30 минут, так что оно уйдёт даже при убитом приложении. Выключатель — «Уведомления → На этом телефоне».

**Напоминания учителю T10.** (Android: `flutter_local_notifications` не добавляет свои ресиверы в манифест; без трёх `<receiver>` в `AndroidManifest.xml` напоминания не срабатывают, а «Одобрить» из data-only пуша ничего не делает.) Локально, через 5 минут после звонка, если посещаемость урока не отмечена; не больше 6 в день; пересчитываются при каждой синхронизации, снимаются при сохранении отметок. Выключатель — там же.

**Что требует реального устройства или консолей**
- Пуши с APNs и их кнопки: симулятор токена не получает; кнопки проверены через `xcrun simctl push` с категорией, сквозной путь — только на устройстве.
- Apple Developer: App ID с Push, App Groups (`group.kz.gradeapp.gradeapp` для приложения и `kz.gradeapp.gradeapp.GradeAppWidgets`), Associated Domains, Live Activities; профили подписи для обоих таргетов.
- Universal Links / App Links проверяются только на устройстве после выкладки `apple-app-site-association` и `assetlinks.json` на grade-app.kz (на Android нужен SHA-256 релизного ключа).
- Виджеты на Xiaomi и Samsung с экономией батареи, Live Activity «не позже звонка + 30 минут» без приложения — только на железе.

```
lib/
  app/            корень: MaterialApp, тема, роутер (go_router), настройки
  core/           api (Dio + refresh single-flight), кэш, офлайн-очередь, шкала и формула четвертной
  ui/             дизайн-система «Веер» (импорт: ui/ui.dart)
    tokens/       цвета light/dark, типографика Onest, отступы, радиусы, глубина, моушн и пружины
    widgets/      таб-бар «капсула», заголовки, лист/группа/плитка, строки, кнопки, чипы,
                  чип оценки, громкий лист и веер, шиты, тосты, скелетон, пустые состояния
    haptics.dart  хаптика по смыслу (success / warning / error — через нативный канал)
  l10n/           ARB ru / kk / en → gen-l10n
  features/
    auth/         вход по паролю (+2FA), по коду из школы, восстановление пароля
    shell/        шелл ролей, шапка (колокольчик, аватар, переключатель ребёнка, индикатор синхронизации), профиль
    common/       модели, «Сейчас / Дальше», строка и карточка урока, неделя, пульс
    student/      «Сегодня» ученика, «Я в школе» (своя камера, овал, «Отмечено»)
    learner/      общее для ученика и родителя: неделя, оценки по ГОСО, предмет, задания
    parent/       итог дня (правила вердикта), обзор семьи, «Отпросить», согласие на фото, «Семья»
    teacher/      «Сегодня», урок (перекличка, пэд оценок, тема, ДЗ, итог), очередь, неделя, входящие
    notifications/ уведомления и переход по target
    platform/     кнопки в пушах, тихая синхронизация, ссылки, виджеты, Live Activity, напоминания
```

## Роли и навигация

| Роль | Табы | В шапке |
|---|---|---|
| Ученик | Сегодня · Неделя · Оценки · Задания | колокольчик, аватар (профиль) |
| Родитель | Сегодня · Оценки · Неделя · Семья | колокольчик, аватар ребёнка (переключатель → профиль) |
| Учитель | Сегодня · Неделя · Входящие | индикатор синхронизации, аватар |

Активная роль и выбранный ребёнок переживают перезапуск (читаются до первого кадра, без мигания чужой роли). Профиль, смена роли и школы, язык и тема — в шите аватара.

## Данные и офлайн

- **State**: Riverpod 3. Серверные данные — `StreamProvider` через `cachedGet`: сразу кэш, потом свежий ответ. Без сети остаётся кэш, а `NetBanner` показывает, от какого времени данные.
- **Авторизация**: access/refresh в Keychain/Keystore, один общий refresh на все параллельные 401 (бэкенд ротирует refresh). Сессию завершает только 401 от `/auth/refresh/`.
- **Офлайн-очередь учителя** (`core/offline/outbox.dart`): посещаемость, оценки, тема, ДЗ, старт и завершение урока сначала пишутся на телефон. Экран урока накладывает неотправленное поверх серверного (`LessonOverlay`). Ответ 4xx не теряет запись: она уходит в «Отклонено» с причиной (`soch_lock`, 403, 404) и ждёт «Повторить» или «Удалить» в листе синхронизации. Выход с непустой очередью требует подтверждения.
- **Четвертная**: `effective_mark` из `/grades/period/`, где он есть; иначе предварительная по формуле школы (`Grading.quarter`, повторяет `backend/journal/grading_service.py`). Простое среднее не показывается.
- **Перекличка**: ростер собирается по всем классам урока (`class_group_id` + `additional_class_groups`). Подгруппа показывается в шапке урока; принадлежности учеников к подгруппам в API нет.

## Правила кода

- Цвета только из `ui/tokens/colors.dart` (`context.c`), текст — `context.t`. Hex в экранах не пишем.
- Строки только через `context.l10n`. ARB генерируются из таблицы строк: правьте все три языка сразу, казахский — отдельно, не калькой с русского.
- Нажатие — `GPressable` (масштаб и пружина), ripple выключен. Анимируются только transform и opacity; переключатели состояний строятся из постоянных слоёв с `AnimatedOpacity`, а не из `AnimatedSwitcher` с повторяющимися ключами.
- Нетривиальная логика покрыта тестами: `test/quarter_test.dart`, `verdict_test.dart`, `outbox_test.dart`, `roll_call_test.dart`, `lesson_overlay_test.dart`, `widgets_test.dart`, `push_test.dart`, `presence_test.dart`, `app_lock_test.dart`, `report_card_test.dart`, `feedback_test.dart`, `homework_upload_test.dart`, `analytics_test.dart`, `crash_reporting_test.dart`, `platform_test.dart`, `lesson_label_test.dart`.
