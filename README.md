# GradeApp Mobile

Flutter-приложение GradeApp для ученика, родителя и учителя. Работает на тех же API, что и веб (`gradeapp/backend`). Дизайн — система «Веер» (`docs/design/`), продукт — `docs/product/`.

## Запуск

```bash
flutter pub get
flutter run --dart-define=API_BASE_URL=http://localhost:8001/api   # локальный бэкенд
flutter run                                                         # прод: https://grade-app.kz/api
```

Базовый URL обязательно с `/api`. Android-эмулятор ходит на хост через `http://10.0.2.2:<port>/api`. После смены нативных зависимостей (камера, шрифты) нужен полный `flutter run`, hot restart не подхватит.

Проверки (их же стоит гонять в CI):

```bash
flutter analyze   # ноль замечаний
flutter test
```

## Пуши (FCM)

Без конфигурации Firebase пуши выключены, остальное работает. Чтобы включить:

1. Создать проект Firebase, добавить приложения iOS и Android с bundle id `kz.gradeapp.gradeapp`.
2. Загрузить в Firebase APNs-ключ (.p8) из Apple Developer (Project settings → Cloud Messaging).
3. Скопировать `firebase.example.json` в `firebase.json` (он в `.gitignore`), заполнить значениями из настроек приложений в Firebase.
4. Запускать с `--dart-define-from-file=firebase.json`.
5. На бэкенде: сервисный аккаунт Firebase (JSON) в переменную `FCM_SERVICE_ACCOUNT`. Отправка — `backend/users/fcm.py`.

Как устроено:
- токен уходит на `POST /api/push/devices/` после входа и только если уведомления разрешены; при выходе — `DELETE`;
- разрешение спрашивается один раз, с пояснением: у ученика после первой отметки «Я в школе», у родителя и учителя через пару секунд после первого открытия;
- в открытом приложении пуш — тост с кнопкой «Открыть»; тап по системному пушу открывает экран по карте §4.3 спеки (и при холодном старте);
- текст пуша собирает сервер на языке пользователя, оценок и баллов в нём нет;
- Android: канал на каждую группу настроек; iOS: бейдж = непрочитанные в колокольчике;
- настройки групп — профиль → «Уведомления» (`notification_prefs`, канал `push`).

## Роли и навигация

| Роль | Табы | В шапке |
|---|---|---|
| Ученик | Сегодня · Неделя · Оценки · Задания | колокольчик, аватар (профиль) |
| Родитель | Сегодня · Оценки · Неделя · Семья | колокольчик, аватар ребёнка (переключатель → профиль) |
| Учитель | Сегодня · Неделя · Входящие | индикатор синхронизации, аватар |

Активная роль и выбранный ребёнок переживают перезапуск (читаются до первого кадра, без мигания чужой роли). Профиль, смена роли и школы, язык и тема — в шите аватара.

## Данные и офлайн

- **State**: Riverpod 3. Серверные данные — `StreamProvider` через `cachedGet`: сразу кэш, потом свежий ответ. Без сети остаётся кэш, а `NetBanner` показывает, от какого времени данные.
- **Авторизация**: access/refresh в Keychain/Keystore, один общий refresh на все параллельные 401 (бэкенд ротирует refresh). Сессию завершает только 401 от `/auth/refresh/`.
- **Офлайн-очередь учителя** (`core/offline/outbox.dart`): посещаемость, оценки, тема, ДЗ, старт и завершение урока сначала пишутся на телефон. Экран урока накладывает неотправленное поверх серверного (`LessonOverlay`). Ответ 4xx не теряет запись: она уходит в «Отклонено» с причиной (`soch_lock`, 403, 404) и ждёт «Повторить» или «Удалить» в листе синхронизации. Выход с непустой очередью требует подтверждения.
- **Четвертная**: `effective_mark` из `/grades/period/`, где он есть; иначе предварительная по формуле школы (`Grading.quarter`, повторяет `backend/journal/grading_service.py`). Простое среднее не показывается.
- **Перекличка**: ростер собирается по всем классам урока (`class_group_id` + `additional_class_groups`). Подгруппа показывается в шапке урока; принадлежности учеников к подгруппам в API нет.

## Правила кода

- Цвета только из `ui/tokens/colors.dart` (`context.c`), текст — `context.t`. Hex в экранах не пишем.
- Строки только через `context.l10n`. ARB генерируются из таблицы строк: правьте все три языка сразу, казахский — отдельно, не калькой с русского.
- Нажатие — `GPressable` (масштаб и пружина), ripple выключен. Анимируются только transform и opacity; переключатели состояний строятся из постоянных слоёв с `AnimatedOpacity`, а не из `AnimatedSwitcher` с повторяющимися ключами.
- Нетривиальная логика покрыта тестами: `test/quarter_test.dart`, `verdict_test.dart`, `outbox_test.dart`, `roll_call_test.dart`, `lesson_overlay_test.dart`, `widgets_test.dart`, `push_test.dart`.
